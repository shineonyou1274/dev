# 스킬 머리말과 함정 섹션 초안 (2026-10-02)

`audit/skill-audit.md`의 1~3번을 바로 고칠 수 있도록, 붙여 넣을 글을 스킬별로 정리했습니다. claude.ai의 스킬 설정에서 해당 스킬의 `SKILL.md`를 열고, 맨 위 `---`에서 `---`까지(머리말)를 아래 초안으로 바꾸면 됩니다. 함정 섹션은 본문 맨 끝에 붙입니다.

머리말 설명(description)은 세 가지 기준으로 다시 썼습니다.

1. "무엇을 하는가"보다 "어떤 요청에서 불러야 하는가"를 먼저 씁니다.
2. 겹치는 스킬이 있으면 "~은 이 스킬이 아니라 ~을 쓴다"를 넣습니다. master-sheet와 storyboard에서 이미 쓰고 있는 방식입니다.
3. "다음 상황에서 반드시 이 스킬을 사용한다"는 "~할 때 사용"으로 줄입니다.

함정 섹션에는 각 스킬 본문에 이미 흩어져 있던 내용만 모았습니다. 제가 지어낸 실수는 넣지 않았으니, 실제로 겪은 실수가 있으면 한 줄씩 더하세요.

## 1. humanizer: 끄기를 권합니다

머리말이 두 번 들어가 있어서, Claude는 첫 번째 머리말의 `"자연스러운 한국어"` 한 줄만 보고 스킬을 고릅니다. plain-korean과 역할도 겹칩니다. plain-korean이 선생님의 기준(교과서체)을 담고 있으므로 humanizer는 끄는 편이 낫습니다.

남겨 두려면 파일 맨 위의 두 블록(첫 번째 머리말과, 그 아래 `name:`부터 `allowed-tools:`까지 이어지는 두 번째 블록)을 지우고 아래 하나로 바꿉니다.

```yaml
---
name: humanizer
description: "이미 쓴 한국어 글에 AI 문체 패턴이 얼마나 있는지 진단만 할 때 사용. 쉼표 과다, 띄어쓰기 경직, 대명사·복수형 과다 등 40가지 패턴을 S1~S3 심각도로 표시해 보고한다. 트리거 예: \"AI 티 나는지 진단해 줘\", \"AI 패턴 분석해 줘\". 새로 쓰는 글과 윤문, 문장 다듬기는 이 스킬이 아니라 plain-korean을 쓴다."
license: MIT
metadata:
  author: DaleSeo
  version: "1.6.0"
allowed-tools: Read Write Edit Grep Glob AskUserQuestion
---
```

## 2. HTML을 만드는 스킬 세 개

세 스킬의 범위를 이렇게 나눕니다. single-html-app이 공통 제작 규칙을 맡고, 나머지 둘은 구조만 맡습니다.

| 스킬 | 맡는 것 | 대표 요청 |
|---|---|---|
| single-html-app | 학생이 휴대폰으로 여는 앱·활동지·게임과, 모든 단일 HTML의 공통 제작 규칙 | "학생용 진단 앱 만들어 줘", "이 활동지 앱으로" |
| guide-panel-layout | 왼쪽 목차와 오른쪽 한 화면 구조의 안내서·매뉴얼 | "연수 실습 가이드 정리해 줘", "사용법 매뉴얼" |
| pd-runsheet | 연수 당일 강사가 띄우는 진행보드(시각, 타이머, 모드 전환) | "연수 진행보드 만들어 줘", "보드 시간표 고쳐 줘" |

### single-html-app

```yaml
---
name: "single-html-app"
description: "학생이 휴대폰으로 여는 단일 HTML 웹앱·활동지·게임을 만들거나 고칠 때 사용. 파트 분할 빌드, 테마 토큰, 아티팩트 제약, 화면 이동, 저장·제출, 내보내기 전 점검을 적용한다. guide-panel-layout과 pd-runsheet로 만드는 HTML에도 이 제작 규칙을 함께 적용한다. 트리거 예: \"앱으로 만들어 줘\", \"단일 HTML\", \"활동지 웹앱\", \"아티팩트로 발행\"."
---
```

본문 끝에 붙일 함정 섹션입니다. 모두 본문 2~3절에서 옮겼습니다.

```markdown
## 함정

- 어두운 화면 색을 `@media` 블록 한쪽에만 선언하면 깨진다. `:root:not([data-theme="light"])`와 `:root[data-theme="dark"]` 두 곳에 같은 값을 넣는다.
- `body`에 배경색을 빼면 바깥 배경이 비친다.
- 아티팩트에서는 `window.print()`, `alert`, `confirm`, `prompt`가 동작하지 않는다. 교실에서 눌러도 아무 일이 일어나지 않는다.
- `localStorage`는 비어 돌아오거나 예외를 던질 수 있다. 읽기와 쓰기를 모두 try/catch로 감싼다.
- 완성본(app.html)을 직접 고치면 다음 빌드에서 사라진다. 언제나 파트 파일을 고친다.
- (실제로 겪은 실수를 여기에 한 줄씩 더한다)
```

### guide-panel-layout

```yaml
---
name: guide-panel-layout
description: "연수 실습 가이드, 안내서, 매뉴얼처럼 덩어리가 네 개 이상인 자료를 왼쪽 목차와 오른쪽 한 화면 전환 구조의 단일 HTML로 만들 때 사용. 고르면 결과가 즉시 만들어지는 도구 패널을 넣는다. 트리거 예: \"연수용으로 정리해 줘\", \"실습 가이드\", \"사용법 매뉴얼\". 연수 당일 강사가 띄우는 진행보드는 이 스킬이 아니라 pd-runsheet를 쓴다. 제작 공통 규칙은 single-html-app을 함께 따른다."
---
```

```markdown
## 함정

- `grid-template-columns`를 `1fr`로만 두면 메뉴의 최소 폭 때문에 모바일에서 본문 전체가 가로로 넘친다. `minmax(0,1fr)`과 `.rail,main{min-width:0}`을 쓴다.
- CSS에 `section[hidden]{display:none}`을 빼면, 클래스에 준 `display`가 `[hidden]`을 이겨 숨긴 절이 보인다.
- 메뉴 라벨을 `textContent` 전체로 읽으면 번호와 제목이 붙어 "02프롬프트 만들기"가 된다. `a.lastChild.textContent`를 쓴다.
- 한글에 넓은 자간을 주거나 mono 글꼴을 쓰면 글자가 흐트러진다. mono와 자간은 숫자·영문 라벨에만 쓴다.
- 색을 미디어 블록 안에서만 정의하면 기본 상태에서 글자가 보이지 않는다.
- (실제로 겪은 실수를 여기에 한 줄씩 더한다)
```

### pd-runsheet

```yaml
---
name: "pd-runsheet"
description: "손평화 선생님의 교사 연수 진행보드(강사가 당일 띄우는 단일 HTML: 시각별 목차, 경과 타이머, 참가자·강사 모드, 프롬프트 복사, 결과물 체크)를 설계·제작·수정할 때 사용. 만들기 전 확인 목록, 블록 설계 규칙, 시간 배분 실측치, 내보내기 전 자가 점검을 적용한다. 트리거 예: \"연수 진행보드\", \"연수 보드 시간표 고쳐 줘\", \"강사용 진행 화면\". 연수 뒤에 나눠 줄 안내서·매뉴얼은 이 스킬이 아니라 guide-panel-layout을 쓴다."
---
```

```markdown
## 함정

- 이전 행사의 공유보드 주소를 그대로 두면 참석자가 엉뚱한 보드에 올린다. 행사마다 주소를 새로 받는다.
- 앱스스크립트 배포는 권한 승인 화면에서 한 명 이상 꼭 막힌다. 그 시간을 시간표에 미리 넣는다.
- 수업 장면을 상상해서 쓰면 틀린다. 예를 들어 자기이해 수업은 검사 결과를 학생이 활동지에 옮겨 적는 방식이지, AI가 성향 문항을 만드는 방식이 아니다. 실제 업무 비중을 먼저 묻는다.
- 긴 프롬프트를 먼저 시키고 나중에 Gem에 담게 하면 순서가 거꾸로다. Gem을 먼저 만든다.
- 주소를 받기 전에 링크 카드를 만들어 비워 두지 않는다.
- (실제로 겪은 실수를 여기에 한 줄씩 더한다)
```

## 3. 활동지를 만드는 스킬의 경계

"활동지 만들어 줘"라는 요청에 news-to-worksheet, suneung-signal-workbook, single-html-app이 모두 후보가 됩니다. 재료와 결과 형식으로 나눕니다.

### news-to-worksheet

```yaml
---
name: news-to-worksheet
description: "입시·교육 뉴스를 재료로 교사용 요약, 학생 활동지(HTML과 DOCX), 블로그 글 두 버전(순수 텍스트와 마크다운)을 만들 때 사용. 뉴스 수집부터 할 수도 있고, 수집한 뉴스 텍스트(.txt)를 받아 시작할 수도 있다. 트리거 예: \"입시 뉴스로 활동지 만들어 줘\", \"뉴스 크롤링해서 수업자료로\", \"교사용 뉴스레터\", \"논술·면접·세특 연계 자료\". 수능 영어 지문으로 만드는 워크북은 이 스킬이 아니라 suneung-signal-workbook을 쓰고, 뉴스가 재료가 아닌 학생용 웹앱은 single-html-app을 쓴다."
---
```

본문의 "⚠️ DOCX 테이블 레이아웃" 경고를 함정 섹션으로 옮깁니다. 원래 자리에는 코드 예시만 남기면 됩니다.

```markdown
## 함정

- DOCX에서 페이지 크기(A4, 11906×16838 DXA)를 명시하지 않으면 Word가 열 폭을 무시한다.
- 표 하나라도 `columnWidths`를 빼면 tblGrid가 100으로 오염되어 뒷 페이지의 열이 찌그러진다. 모든 표에 `columnWidths`를 넣고, `WidthType.PCT`와 `PERCENTAGE`는 쓰지 않는다.
- 시작 전에 `npm install -g docx`가 되어 있는지 확인한다.
- (실제로 겪은 실수를 여기에 한 줄씩 더한다)
```

### suneung-signal-workbook

```yaml
---
name: suneung-signal-workbook
description: "수능 영어 지문(요지·주제·제목 유형)에 신호등 독해법을 적용해 단계별 학습 워크북(.docx)을 만들 때 사용. 소재 연결(Chaining), 신호등(연결사), 통합 적용 순서로 구성하며, 지문이 달라도 같은 구조를 쓴다. 트리거 예: \"신호등 독해법으로 이 지문 워크북\", \"수능 영어 요지 문제 활동지\", \"이 기출 지문 학생 활동지로\". 뉴스가 재료인 활동지는 news-to-worksheet를 쓴다."
---
```

이 스킬에는 이미 "주의사항 ⚠️ (Node.js 22 파싱 버그)" 절이 있습니다. 제목을 `## 함정`으로 바꾸기만 하면 됩니다.

## 4. "반드시 사용한다"를 줄일 스킬

### expert-panel

"어때?", "봐줘"는 아주 흔한 말이라 범위가 넓습니다. 한 줄 확인에도 패널 전체가 돌지 않도록, 결과물 검토일 때로 좁힙니다.

```yaml
---
name: expert-panel
description: "손평화 선생님의 결과물(수업자료, 앱, 교과서, 활동지, 기획안)이나 새 설계 방향을 여러 전문가 관점에서 검토할 때 사용. 고정 코어 4명과 상황별 전문가 1~2명이 따로 평가한 뒤 종합하고, 놓친 점(blind spot)을 남기지 않는다. 트리거 예: \"이거 어때?\", \"문제없어?\", \"검토해 줘\", \"봐줘\" (결과물이나 기획을 함께 줄 때). 사실 하나를 확인하는 짧은 질문에는 쓰지 않는다. 가정 자체를 뒤집는 사고가 필요하면 first-principles를 쓴다."
---
```

### first-principles

```yaml
---
name: first-principles
description: "당연하게 여기던 가정을 뜯어보고 문제를 근본부터 다시 설계할 때 사용. 제1원칙 사고법으로 가정을 분류하고 새 해결책을 낸다. 트리거 예: \"근본적으로\", \"왜 이렇게 해야 하지\", \"완전히 다른 방법\", \"당연한 게 맞나\", \"구조 자체를 바꾸고 싶다\", \"제1원칙\", \"first principles\". 단순 정보 질문, 바로 실행할 요청, 위로가 필요한 상황에는 쓰지 않는다. 이미 만든 결과물의 검토는 expert-panel을 쓴다."
---
```

## 고친 뒤 확인하는 법

1. 새 세션을 열고 `/skills`(또는 스킬 목록)에서 설명이 바뀌었는지 봅니다.
2. 아래 요청을 하나씩 보내고, 의도한 스킬이 불리는지 봅니다.

| 요청 | 불려야 하는 스킬 |
|---|---|
| 이 글 좀 자연스럽게 다듬어 줘 | plain-korean |
| 연수 실습 가이드를 정리해 줘 | guide-panel-layout |
| 다음 주 연수 진행보드 만들어 줘 | pd-runsheet |
| 학생용 진로 진단 앱 만들어 줘 | single-html-app |
| 이 수능 지문으로 활동지 만들어 줘 | suneung-signal-workbook |
| 오늘 입시 뉴스로 활동지 만들어 줘 | news-to-worksheet |

엉뚱한 스킬이 불리면 그 스킬의 설명에 경계 문장을 한 줄 더합니다. 이 표를 늘려 가면 PDF 11장의 `/claude-api build-eval`에 넣을 평가 세트가 됩니다.
