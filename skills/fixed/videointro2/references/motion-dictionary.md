# 모션 기법 사전 연결 (awesome-ai-motion)

`https://github.com/gongnyang/awesome-ai-motion`은 AI 에이전트가 읽도록 만든 모션 기법 사전이다(MIT 라이선스, 2026년 9월 기준 기법 637개, 기준 클립 128개, 레시피 11개). 기법마다 카드(`effects/<slug>/README.md`)가 있고, 카드에 정의, 고르는 기준, 기본 파라미터, 좋은 예와 나쁜 예, 과용 주의, 구현 코드가 있다.

이 스킬에 복사하지 않는다. 필요할 때 내려받아 카드만 읽는다.

```bash
git clone -q --depth 1 https://github.com/gongnyang/awesome-ai-motion $SCRATCH/aim
```

## 쓰는 때

2단계(장면 표)에서 장면마다 "어떤 움직임을 쓸까"를 정할 때 후보를 고르는 목록으로 쓴다. 이야기는 이 사전이 정해 주지 않는다. 도형과 색의 뜻은 1단계에서 먼저 정한다.

## 순서

1. 장면의 목적을 한 단어로 정한다. 사전의 목적 값은 `주목 끌기, 설명, 비교, 순서·흐름, 강조, 전환, 데이터 증명, 피드백, 분위기, 브랜딩`이다.
2. `references/decision-tables.md`에서 그 목적의 후보를 2~3개 고른다. 목적별로 바로 뽑으려면 다음을 쓴다.
   ```bash
   jq -r '.effects[] | select(.render=="done" and (.purposes|index("브랜딩"))) | .slug' $SCRATCH/aim/index.json
   jq '.effects[] | select(.slug=="light-sweep") | {params, ease}' $SCRATCH/aim/index.json
   ```
3. 후보 카드의 "선택 기준"과 "주의"를 읽는다. 그리고 **"이 움직임은 이야기에서 무엇인가"**를 한 줄로 적는다. 답이 없으면 다른 후보를 고른다.
4. 카드의 기본 파라미터(시간, 각도, 배율, 속도비)를 그대로 가져와 `seek(t)` 안의 시간 함수로 옮긴다. 사전의 구현은 GSAP 타임라인이지만, 우리 렌더러는 모든 값을 시간의 순수 함수로 계산해야 한다(모션 블러를 위해 한 프레임을 여러 번 찍기 때문).
5. 장면 표에 사용한 카드 이름(slug)을 적어 둔다.

## GSAP 이징을 kinetic.js로 옮기기

| 카드의 이징 | seek(t)에서 |
|---|---|
| `none` | `lin(t, a, b)` |
| `power1.in` | `lin(t,a,b) ** 2` |
| `power1.inOut` | `p < .5 ? 2*p*p : 1 - (-2*p+2)**2/2` |
| `power2.out` | `1 - (1-p)**3` |
| `power3.inOut` | `ease(p)` |
| `power3.out` | `1 - (1-p)**4` (= `eout`) |
| `power4.out` | `1 - (1-p)**5` |
| `back.out`, `elastic` | `spr(t, t0, f, z)` |

## 광고에 특히 쓸 만한 카드

| slug | 무엇 | 우리 식으로 쓰는 예 |
|---|---|---|
| `kinetic-type-sweep` | 큰 글자 여러 줄이 서로 다른 속도로 흐르다가 핵심어 하나만 가운데 급정지 | 소음 의성어가 흐르다 "쉿"만 멈춤. 줄별 속도비 1.5배 이상, 급정지 0.3초 `power4.out`, 나머지 줄은 13%로 가라앉힘 |
| `particle-assemble` | 흩어진 입자 수백 개가 날아와 숫자·로고를 이룸 | 흩어진 소음 조각이 모여 브랜드 이름이 됨. 입자 600~1200개, 먼 입자가 늦게 도착, 도착 뒤 흔들지 않음 |
| `light-sweep` | 기울어진 빛 띠가 글자 안쪽만 한 번 지나감 | 제품의 광택, 로고 확정. 112도, 1.5초, 한 장면에 한 번만 |
| `giant-mask-reveal` | 큰 글자가 창이 되고 카메라가 획 속으로 들어감 | 로고나 숫자 안의 세계로 들어가는 오프닝. 배율은 지수(12^p)로 |
| `morph-match-cut` | 모양이 같은 두 물체를 모프로 잇기 | 도형 하나가 다음 장면의 물체가 됨 |
| `iris-mask`, `zoom-through` | 원형 창, 확대로 통과 | 점이 세계가 되는 전환 |

## 주의

- 사전의 기본 분위기는 교육·설명 영상이라 차분하다. 우리 영상에서는 빌드업, 무음, 터짐의 강약 안에 넣어 쓴다.
- 사전의 카드는 부품이다. 한 영상에 카드를 많이 섞지 않는다. 영상마다 2~4개를 고르고, 같은 카드를 두 장면 연속으로 쓰지 않는다.
- 카드의 "나쁜 예"와 "주의"를 꼭 읽는다. 대부분의 실패(입자 수가 적어 모양이 안 읽힘, 빛 띠가 여러 번 지나가 번쩍임)가 거기 적혀 있다.
