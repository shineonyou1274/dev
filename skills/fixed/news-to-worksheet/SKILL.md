# 입시뉴스 → 수업 활동지 파이프라인 스킬

이 스킬은 세 단계로 구성된다. 사용자가 어느 단계에서 시작하는지 파악하고 그 지점부터 진행한다.

```
[1단계] 뉴스 수집      →  [2단계] 활동지 생성     →  [3단계] 블로그 포스트 생성
 크롤러 Python 코드        HTML + DOCX 파일           순수 텍스트 + 마크다운 버전
```

사용자가 이미 수집된 뉴스 텍스트를 갖고 있다면 → **2단계부터** 시작  
활동지까지 완료하고 블로그 글만 원한다면 → **3단계부터** 시작

---

## 1단계: 뉴스 수집 크롤러

세부 구현은 `references/crawler.md`를 읽고 따른다.

**핵심 원칙:**
- 링크 필터: `find_all('a')` 전체 수집 금지 → 사이트별 `link_filter` 패턴 지정
- 링크 보정: `site['url'] + link` 방식 금지 → `urljoin(get_base_url(url), raw_link)` 사용
- API 호출: Rate limit 429 발생 시 모델 폴백 + 자동 재시도 (`references/gemini-retry.md` 참고)
- 출력: `교사용_입시데이터_통합본.txt` 고정 포맷으로 저장

**프롬프트 고정 포맷** (이 순서와 항목명을 그대로 유지):
```
분류: [대입제도/논술/전형변화] / [세부분류] / 활용도 [높음/중/낮음]
교사용 제목: (25자 이내)
핵심 내용 1줄 요약: (40자 이내)
진학지도 포인트:
2027·2028 대입 연결성: [직접/간접/약함]
학교 현장 적용 메모:
```

---

## 2단계: 활동지 생성

수집된 뉴스 텍스트 또는 사용자가 붙여넣은 뉴스 내용을 분석하여 두 가지 파일을 생성한다.

### 2-A. 뉴스 분류 및 주제 선별

입력 뉴스를 다음 기준으로 분류한다:

| 활용도 | 기준 | 처리 |
|--------|------|------|
| 높음 | 2027·2028 대입 직결, 논술·면접 개념 연계 가능 | 활동지 주제로 채택 |
| 중 | 전형 변화 정보, 분석 가능한 데이터 포함 | 분석형 섹션으로 채택 |
| 낮음 | 단순 정보성, 현장 적용 연결 약함 | 제외 또는 참고 자료로만 언급 |

### 2-B. HTML 활동지

세부 구현은 `references/html-worksheet.md`를 읽고 따른다.

**고정 5단계 구조** (주제마다 동일하게 적용):
1. 뉴스 읽기 + 배경 지식 점검 (5분)
2. 핵심 개념 내 언어로 정리 (10분) — 세특 직결
3. PMI + 윤리 프레임 다각도 사고 (10분) — 면접 직결
4. 모의 면접 질문 & 답변 설계 (10분)
5. 세특 연계 문장 빈칸 채우기 (5분)

**필수 UI 요소:**
- 주제 탭 전환 (topic-btn / topic-content 패턴)
- `contenteditable` + `data-placeholder` 작성 영역
- PMI 2×2 그리드 (Plus / Minus / Interesting / 내 입장)
- 면접 Q/A 대화 카드 (면접관 질문 고정 + 답변 작성)
- 세특 문장 빈칸 채우기 (`setech-fill` span)
- 공통 자기평가 체크리스트 (기초→최상위 6단계)
- 인쇄/PDF 저장 버튼

### 2-C. DOCX 활동지

세부 구현은 `references/docx-worksheet.md`를 읽고 따른다.

**필수 준수 사항:**
- `npm install -g docx` 사전 확인

#### ⚠️ DOCX 테이블 레이아웃 — 반드시 준수 (어기면 뒷 페이지 열 찌그러짐)

```javascript
// ① 페이지 크기 필수 명시 (없으면 Word가 열 폭을 무시함)
const PAGE_W   = 11906;  // A4 DXA
const PAGE_H   = 16838;
const MARGIN   = 900;
const CONTENT_W = PAGE_W - MARGIN * 2; // 10106

page: { size:{width:PAGE_W,height:PAGE_H}, margin:{top:MARGIN,...} }

// ② 모든 테이블에 columnWidths 필수 (없으면 tblGrid=100 오염 → 뒷 페이지 붕괴)
new Table({ width:{size:CONTENT_W,type:WidthType.DXA}, layout:TableLayoutType.FIXED,
  columnWidths:[열폭...], rows })  // WidthType.PCT/PERCENTAGE 금지

// ③ columnWidths: 1열=[CONTENT_W], 2열균등=[hw,hw], 2열라벨/값=[lw,CONTENT_W-lw]
```

#### 📐 셀 테두리 & 마진 기준 양식 (2026-05-13 기준)

| 셀 유형 | 테두리 | 마진(top/bottom/left/right) |
|--------|--------|---------------------------|
| 헤더(DEEP_NAVY/DARK 배경) | 없음(nil) | 100/100/150/150 |
| 정보박스 라벨/값 | 네이비 사방 sz=6 | 80/80/120/120 |
| 뉴스요약·활동안내(INFO) | 네이비 L자(top+left) sz=12 | 100/100/150/150 |
| PMI 4칸 | 네이비 사방 sz=6 | 100/100/120/120 |
| 5단계 세특(WARN) | 오렌지 L자(top+left) sz=12 | 100/100/150/150 |
| 주제선택 셀 | 네이비 사방 sz=6 | 80/80/120/120 |

- 배경색: `ShadingType.CLEAR` (SOLID 금지 — 검은 배경 버그)
- 줄바꿈: `\n` 금지 → 별도 `Paragraph` 요소로 분리
- 생성 후 outputs 폴더에 저장 → `present_files` 호출

## 3단계: 블로그 포스트 생성

활동지 제작 과정과 결과물을 두 가지 버전으로 작성한다.
사용자가 특별히 지정하지 않으면 **두 버전 모두** 생성한다.

### 버전 A — 활용도 중심 (순수 텍스트)
- **대상**: 교사 커뮤니티 (인디스쿨, 밴드, 카카오채널)
- **형식**: 마크다운 없음. 줄바꿈과 단락으로만 구성
- **톤**: 교사가 교사에게 쓰는 말투. "이 수업에서 얻은 것"
- **포함 내용**: 뉴스 선별 이유 → 활동지 설계 논리 → 수업 흐름 → 활용 방법 3가지 → 재사용 가이드

### 버전 B — 기술 중심 (마크다운)
- **대상**: 에듀테크·개발자 블로그 (GitHub Pages, 티스토리, 노션)
- **형식**: 마크다운 코드블록 포함, 복붙 즉시 가능
- **포함 내용**: 파이프라인 전체 흐름도 → 크롤링 구현 → API Rate Limit 처리 → HTML 활동지 핵심 코드 → DOCX 트러블슈팅 → 최종 출력물 표 → 향후 개선 방향

---

## 출력 체크리스트

단계가 완료될 때마다 확인:

- [ ] 1단계: `교사용_입시데이터_통합본.txt` 생성됨
- [ ] 2-B: `입시뉴스_활동지.html` → outputs 폴더에 복사 → present_files 완료
- [ ] 2-C: `입시뉴스_활동지.docx` → outputs 폴더에 복사 → present_files 완료
- [ ] 3: 버전 A (순수 텍스트) 작성 완료
- [ ] 3: 버전 B (마크다운) 작성 완료

## 함정

- DOCX에서 페이지 크기(A4, 11906×16838 DXA)를 명시하지 않으면 Word가 열 폭을 무시한다.
- 표 하나라도 `columnWidths`를 빼면 tblGrid가 100으로 오염되어 뒷 페이지의 열이 찌그러진다. 모든 표에 `columnWidths`를 넣고, `WidthType.PCT`와 `PERCENTAGE`는 쓰지 않는다.
- 시작 전에 `npm install -g docx`가 되어 있는지 확인한다.
