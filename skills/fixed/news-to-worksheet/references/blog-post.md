# 블로그 포스트 생성 레퍼런스

이 스킬에서 생성하는 블로그 포스트는 항상 두 버전이다.

---

## 버전 A — 활용도 중심 (순수 텍스트)

### 목적
교사 커뮤니티(인디스쿨, 밴드, 카카오채널)에서 바로 복붙 가능한 글.
마크다운 렌더링이 안 되는 환경을 전제한다.

### 형식 규칙
- 마크다운 기호 완전 금지 (`#`, `**`, `-`, `` ` `` 등)
- 줄바꿈과 단락 구분만 사용
- 소제목은 한 줄 독립 텍스트로 처리 (예: `입시 뉴스가 수업 활동지가 되기까지`)
- 표 금지, 코드블록 금지

### 필수 포함 내용 (이 순서 권장)
1. 도입: 왜 이 작업을 시작했는가 (공감 포인트)
2. 뉴스 선별 과정: 어떤 기준으로 골랐는가
3. 활동지 설계 논리: 5단계 흐름과 각 단계의 교육적 의도
4. 수업 시간 배분: 45분 기준 구체적 숫자 제시
5. 활용 방법 3가지: 단원 수업 / 진학상담 / 자기주도학습
6. 마무리: 재사용 가이드 (뉴스만 바꾸면 매주 새 수업)

### 톤
- 교사가 교사에게 쓰는 말투
- "했다" 체 또는 "한다" 체 (존댓말 금지)
- 800~1200자 분량

---

## 버전 B — 기술 중심 (마크다운)

### 목적
에듀테크·개발자 블로그(GitHub Pages, 티스토리, 노션)에서 바로 복붙 가능.
마크다운이 렌더링되는 환경을 전제한다.

### 형식 규칙
- 마크다운 헤더(`##`, `###`), 코드블록(` ``` `), 표, 인라인 코드 적극 사용
- 최상위 헤더는 `#` 1개 (문서 제목)
- 코드블록에는 언어 명시 (` ```python `, ` ```javascript `, ` ```bash `)

### 필수 포함 섹션 (이 순서)
```
# 제목

## 개요

## 1. 파이프라인 전체 흐름
   - 아스키 아트 흐름도

## 2. 크롤링 구현
   - 링크 필터 코드
   - urljoin 보정 코드

## 3. Gemini API 연동 및 Rate Limit 처리
   - 문제 상황 (에러 메시지 발췌)
   - 해결 전략 (폴백 코드)
   - 프롬프트 설계

## 4. HTML 활동지 생성
   - 핵심 기능 코드 3개 (탭 전환, contenteditable, 인쇄)

## 5. DOCX 활동지 생성
   - 트러블슈팅 표 (증상 / 원인 / 해결)
   - 핵심 코드 패턴

## 6. 최종 출력물
   - 파일별 용도 표

## 7. 향후 개선 방향
   - 스케줄러, Drive API, 학교별 커스터마이징, 유료 전환
```

### 톤
- 기술 블로그 말투 ("구현했다", "사용했다", "발생한다")
- 존댓말 금지
- 2000~3000자 분량 (코드 포함)
