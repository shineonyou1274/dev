# Signal Reading Method — Core Principles
# 신호등 독해법 핵심 원리

## PART 1: 3대 구조 공식

### 1. 역접 구조 (가장 중요)
```
도입 (현상/일반적 생각)
↓
But / However / Yet / While / Although  ← 전환점
↓ 필자의 핵심 주장 ← 정답 근거
```

### 2. 양보절 + 주절 구조
양보절 = 인정 → 버려라  /  주절 = 핵심 → 정답

접속사형: Although / Though / While / Whereas / Even though / Granted that
전치사형: Despite / In spite of / Regardless of / Notwithstanding / For all ~
기타: Even so / Nevertheless / Nonetheless / Yet

### 3. 재진술 구조
Indeed / In fact / In short / Therefore / This means that / As a result
→ 이 표현 뒤 문장 = 필자가 마지막으로 강조하는 핵심

---

## PART 2: 가치판단 형용사 신호등

이 단어가 있는 문장 = 주제문일 확률 높음

중요성/필수성: essential / vital / crucial / critical / significant / important
              fundamental / primary / main / key

타당성/합리성: sensible / reasonable / appropriate / valid / legitimate / justified

독특성/특별함: unique / distinctive / peculiar / inherent / characteristic
              particular / notable / remarkable

역설/반전: paradoxical / ironic / counterintuitive / unexpected / surprising
          → 제목·주제 문제 핵심 포인트

---

## PART 3: 메타 신호 표현

강조: Let there be no doubt / It is no coincidence that / What matters is
     Above all / Only ~ can / It is worth noting that

필자 주장: Indeed / In fact / The point is / This means that / I would argue

오해 차단 (뒤 내용 = 오답 선지 소재):
  This is not to say / It is not simply that / Not A but B

역설/반전 (뒤 내용 = 제목·주제 정답):
  Paradoxically / Ironically / Far from ~ing / isn't actually / Contrary to belief
  Counterintuitively

---

## PART 4: 실전 체크리스트

Step 1: 역접 접속사에 동그라미 → 주장의 시작점
Step 2: 양보절 표시 → 주절이 핵심
Step 3: 가치판단 형용사에 밑줄 → 주제문 신호
Step 4: 역설 표현 표시 → 제목·주제 핵심
Step 5: 마지막 1~2문장에 별표 → 요지 위치
Step 6: 반복되는 추상명사 세기 → 주제어 확인

핵심: 수능 영어는 내용 이해보다 구조 파악이 먼저!
      구조가 보이면 100% 몰라도 정답을 찾을 수 있다.

## Chaining (소재 연결) 원리

필자는 같은 단어를 반복하지 않고 동의어·상위어·대명사로 변주한다.
이 연결 고리를 끊지 않고 따라가는 것이 유기적 독해의 핵심.

추적 방법:
1. 첫 문장의 주인공(핵심 추상명사) 찾기
2. 이후 문장에서 같은 개념을 가리키는 다른 단어 찾기
3. 문장 번호 순으로 체인 작성
4. 마지막 문장의 단어가 첫 문장 주인공과 연결되는지 확인

변신 패턴:
- 동의어: coopetition → cooperation and competition (동시 병기)
- 상위어: social media → digital communication
- 대명사: belonging → it / this
- 추상화: paranoid → sensible to question / less defensive
