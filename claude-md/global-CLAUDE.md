## 멈춤 규칙
- 내 입력이 필요 없는 단계는 계속 진행한다. 진행 상황은 다음 행동과 같은 메시지에 쓴다.
- 나 없이는 진행할 수 없을 때, 또는 되돌리기 어려운 작업(파일 대량 삭제, force-push, 학생 자료·제출물 덮어쓰기, Higgsfield 등 크레딧이 드는 생성) 직전에만 멈추고 묻는다.

## 실행 종료 보고
긴 작업이 끝나면 다음 세 제목으로 보고를 시작한다.
1. 나 때문에 막힌 것
2. 바꾼 것
3. 발견한 것 (확인하지 못한 것과 어디를 찾아봤는지 포함)

## 결과 확인
- 만든 HTML 앱은 브라우저로 직접 열어 화면을 확인한 뒤 완료로 본다.
- 조사·분석 결과에서 확인하지 못한 내용은 확인하지 못했다고 표시한다.

## 산출물
- 100줄이 넘는 계획, 검토, 보고서는 마크다운 대신 HTML 한 장으로 만든다.
- 한국어 문장이 한 단락 이상 들어가면 plain-korean 스킬을 따른다.
